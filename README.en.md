# python-cn-maps-skill

**Portable agent skill** for China map plotting with **matplotlib**, **Cartopy**, **cnmaps**, and **frykit**.

Works with Cursor, Claude Code, Codex, GitHub Copilot, Gemini CLI, OpenCode, and other agents.

[中文 README](README.md) · Install: [docs/INSTALL.md](docs/INSTALL.md)

## Install

```bash
git clone https://github.com/liucmys/python-cn-maps-skill.git
cd python-cn-maps-skill
./scripts/install.ps1 -Target cursor -Scope project   # Windows
# ./scripts/install.sh --target claude --scope project  # macOS/Linux
```
